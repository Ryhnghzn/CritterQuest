# Bos dengan Jurus Khas — Rencana Kerja (Proyek B §41.2)

> **Untuk agen:** kerjakan per bagian (B1–B4). Berhenti di akhir tiap bagian untuk cek manual oleh pemilik (agen cukup `npm test`, `npm run build`, jalankan server lokal dan beri alamatnya). Commit setelah pemilik oke. Centang langkah yang selesai.

**Tujuan:** tiap bos terasa beda dari bentuk, peluru, dan jurusnya. Bentuk bos sudah selesai (commit `87bc070`, `app/bos.html`). Pemilik (2026-11-11): "skill serangnya seharusnya beda-beda bentuknya". Semua peluru musuh saat ini bola cahaya yang hanya beda warna (`render3d/actors.js` `fx3d`, `render/world.js` `enemyShots`).

**Arsitektur:**
- `data/enemies.js`: `look` pada konfigurasi peluru (`ring`, `spiral`, `shot`) dan `slam`; jurus khas & fase per bos.
- `run/enemies.js`: `fire()` membawa `look`; jurus khas di `stepPattern`; jenis hazard baru seperlunya (`zone`, `push`).
- `art/pix/fx.js`: gambar peluru pixel per `look` (murni, tanpa `Math.random`), dites di `fx.test.js`.
- `render3d/spell3d.js`: peluru ber-`look` jadi billboard bergambar (ikut arah terbang / berputar); `data/spell3d.js` `shots` (ukuran, fps, cahaya).
- `render/world.js`: cadangan 2D (`?2d`) menggambar bentuk sederhana per `look`; motif zona bahaya per bos (garis merah tetap ada supaya terbaca).
