# Tampilan 2.5D (dunia 3D, karakter 2D gaya D)

Keputusan pemilik (2026-10-28): setelah mencoba `app/kota3d.html` — "lakukan perubahan menjadi 2.5d"; UI usulan (`app/ui.html`) disetujui.
Kontrol: kamera tetap miring dari belakang (tanpa putar bebas) + zoom (gulir / cubit); kontrol lain tetap seperti sekarang (HP: dua joystick).

Permintaan tambahan pemilik: efek lebay di zirah/gear tetap ada (digambar menempel di gambar karakter), dan jangan lag di HP spesifikasi rendah (mode Ringan: tanpa bloom, resolusi & lampu dikurangi, lapisan efek beresolusi rendah dan diperbarui tiap 2 frame).

Prinsip:
- Logika `run/`, `meta/`, data, save **tidak berubah**. Tampilan baru di `src/render3d/` (Three.js, paket npm `three@0.170.0`, bukan CDN — bisa dimainkan tanpa internet).
- Semua bentuk dibuat lewat kode (aturan "tanpa file gambar" tetap).
- Karakter, monster, NPC, ikon, efek 2D yang sudah ada **dipakai ulang**: karakter & monster jadi gambar tegak (billboard), efek/bahaya/aura 2D digambar ke lapisan transparan di lantai, lantai ruangan digambar sekali per lantai dengan `drawRoom` lalu jadi tekstur.
- Jalur 2D tetap ada selama transisi (panel cheat / `?2d`). Pilihan resmi di Pengaturan menyusul (versi pengaturan naik + `migrate()`), setelah sesi lain selesai mengubah `meta/schema.js`.
- Batas lampu per adegan + kualitas mengikuti pengaturan Efek (Penuh/Ringan).
